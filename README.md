## 🌟 改版優化重點（依 Antigravity 交接清單）

1. **商品圖與購買動線優化**：
   - 首屏縮圖與主圖依序為：**紅瑪瑙 ‧ 粉水晶 ‧ 多款合照 ‧ 綠東陵石**。
   - 縮圖增加清晰的文字標籤、外框選中標識、`aria-current` 與鍵盤操作支援。
   - 首張主圖使用 `fetchpriority="high"` 優先渲染，四款縮圖採用壓縮小檔，縮圖下載量由 7.1 MB 驟降至 < 95 KB，首屏加載極速流暢。
   - 六大購買入口文案統一為「到全家好賣＋選購」與「前往商品頁」，所有連結皆導向官方好賣+賣場：
     `https://famistore.famiport.com.tw/famistore/users/1073868/merchandises/6afe5ee82737c864abf11997`
2. **手機版首屏與固定列調整**：
   - 手機首屏順序精準優化：**品名標題 ➔ 主圖畫廊 ➔ 尺寸與取貨摘要 ➔ 價格 NT$199 與主按鈕 ➔ 服務保障**，最快速度呈現關鍵轉化元素。
   - 頂部導航列高度設為明確的 `h-[72px]`，所有段落跳轉錨點加上 `scroll-mt-[72px]` 偏移量，徹底解決標題被導覽列遮擋問題。
   - 手機吸底列加入 iOS 底部安全區 `env(safe-area-inset-bottom)` 適配，頁尾底部預留對應高度避免內容被蓋住。
   - 商品規格明細改為窄螢幕（320px）友善折行排版，加深原價與說明小字色彩對比。
3. **無障礙與微互動升級**：
   - FAQ 手風琴全面支援 `aria-expanded` 與 `aria-controls`，支援鍵盤 Focus 與 Enter/Space 切換。
   - 新增右下角浮動快捷按鈕（回到頁首 / 直達頁尾），滾動超過 180px 平滑浮現，手機端自動避開吸底下單列。
